# 📘 Apresentação | Project Overview

## 🇧🇷 Português

Olá, caros! 👋  
Este repositório foi criado com o objetivo de desenvolver um **banco de dados relacional** para o projeto da disciplina **Modelagem e Projeto de Banco de Dados**, ministrada pelo **Prof. Vito Rodrigues Franzosi**, nos cursos de Tecnologia da Informação da **UniSales – Centro Universitário Salesiano**.

Para a modelagem e implementação do banco de dados, utilizamos o **SGBD MySQL**, com foco em aplicar os conceitos estudados em aula na prática.

## 🇺🇸 English

Hello everyone! 👋  
This repository was created for the development of a **relational database** as part of the course **"Database Modeling and Design"**, taught by **Professor Vito Rodrigues Franzosi**, in the Information Technology programs at **UniSales – Centro Universitário Salesiano**.

We used the **MySQL DBMS** to design and implement the database, putting into practice the theoretical concepts learned during the course.
